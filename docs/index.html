Install in ten minutes

Needs Node.js 24, Git, and an agent that runs commands: Claude Code, Codex, or Cursor.

  1. Add the skill

    Claude Code: paste this into a session.

    Install the Coresearch skill from https://github.com/praveen221/coresearch into ~/.claude/skills/coresearch, then set it up.

    Other agents: clone it, then say “Read ~/coresearch/SKILL.md and set up Coresearch.”

    git clone https://github.com/praveen221/coresearch ~/coresearch

  2. Choose your folder

    Your agent asks where to keep your research, then opens the app at 127.0.0.1:3780.

  3. Tell it about you

    Upload your CV, add professors or a Google Sheet, and ask it to rank them.

Cost and troubleshooting
Cost
About half a million tokens and 40 minutes per research idea. Batches start only when you approve.
Reasoning
Strongest setting for research; lighter for edits.
node:sqlite errors
Use Node.js 24.14 or a later 24.x release.
engine Not compatible
Node 22 or older is first on PATH. Install Node.js 24.14+, check node -v, then npm ci. Do not bypass the engine check.
Port in use
Say “start Coresearch on port 3790”.
Sharing
Export from the Share page, or share it live over Tailscale (README).

Yours alone

  • Your data stays in a folder on your computer.
  • No account, server, or tracking.
  • It never contacts anyone; you send every email.
